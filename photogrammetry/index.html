gcp_list.txt (OpenDroneMap / WebODM)

How to process

  1. WebODM: Create a task, select all your photos and gcp_list.txt together, then start processing. WebODM detects the GCP file automatically.
  2. ODM (command line / Docker): put photos in project/images/ and gcp_list.txt in project/, then run
    docker run -ti --rm -v /path/to/project:/datasets/code opendronemap/odm --project-path /datasets --gcp /datasets/code/gcp_list.txt
  3. Pix4D / Metashape / DJI Terra: import the GCP coordinates CSV (X = Easting, Y = Northing) and use the image-marks CSV as a reference for placing marks.
In gcp_list.txt Easting comes before Northing (x, y, z). The app handles this for you — you only ever type Northing, Easting, Elevation.

Save / load project

Settings, GCPs and tags are also auto-saved in this browser. Photos are not saved — re-select the same files to continue; tags reconnect by file name.
